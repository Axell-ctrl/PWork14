Практическая работа №14.

Задание: Описать структуру с именем "Автовокзал", содержащую следующие поля: название начального пункта маршрута, название конечного пункта маршрута, номер маршрута, длина маршрута.
Программа должна выполнять следующие действия:
1) ввод с клавиатуры данных, состоящих из n структур типа Автовокзал;
2) записи вывести упорядоченными по номерам маршрутов;
3) вывод на экран информации о наибольшем по длине маршруте (если таких несколько, вывести информацию о каждом из них).
